
# Detection of Aneuploidies with NGS Coverage Data

Utilizing coverage data from next-generation sequencing (NGS), this repository provides a tool for conducting an analysis to identify autosomal or sex chromosome aneuploidies. The environment is fully encapsulated via Docker to ensure reproducibility and facilitate their execution in different environments.

---

## **Installation** 

```bash
docker build -t aneuploidiesstudy /path/to/Dockerfile/Directory
```

---

## **Usage**

The subsequent commands can be executed from the command line to utilize the tool's functions.

### 1. coverage_rdata function:

Starting from coverage files generated by `samtools depth` (with the output structure obtained with samtools v1.3.1), this function generates a `.RData` summarizing coverage data for each evaluated sample.

##### **Command:**

```bash
AneuploidiesStudy coverage_rdata -d <directory> -f <output_name.RData>
```

**`-d` / `--directory`**: Directory where the coverage files generated by `samtools depth` are located.

**`-f` / `--outputfile`**: (Optional) Name of the output `.RData` file. The default value is `Coverage.RData`.

##### **Example:**

```bash
docker run aneuploidiesstudy:latest AneuploidiesStudy coverage_rdata -d /appdata/test_data/ControlCoverage_files

docker run aneuploidiesstudy:latest AneuploidiesStudy coverage_rdata -d /appdata/test_data/PoolCoverage_files
```

##### **Output:**

- A dataframe containing 48 columns that contain the average coverage values for each chromosome, the autosomal set, and the autosomal set excluding one autosome at a time for each processed sample.

### 2. cohort_study function:

This function generates a report in HTML format and other descriptive outputs by analyzing the control cohort from `.RData` generated with the coverage_rdata function.

##### **Command:**

```bash
AneuploidiesStudy cohort_study -c <control.RData> -b <file.bed> -g <genome> -t <threshold> -y <thresholdsignif> -o <output_dir> -f <output_report.html>
```

**`-c` / `--control`**: `.RData` file of the control cohort previously generated with `coverage_rdata`.

**`-b` / `--bed`**: (Optional) BED file with regions of interest.

**`-g` / `--genome`**: (Optional) Reference genome, default is hg38.

**`-t` / `--threshold`**: (Optional) Sample filtering threshold. Default value is 50.

**`-y` / `--thresholdsignif`**: (Optional) Threshold to define significantly different synthetic samples. Default value is 5.5.

**`-o` / `--outputdir`**: (Optional) Output directory. If not provided, the directory of the control `.RData` file will be used.

**`-f` / `--outputfile`**: (Optional) Name of the report in HTML format. Default value is `ControlCohort_report.html`.

##### **Example:**

```bash
docker run aneuploidiesstudy:latest AneuploidiesStudy cohort_study \
  -c /appdata/test_data/ControlCoverage_files/Coverage.RData
```

##### **Output:**

- An HTML report that includes the results of a mean-based filtering of autosomal reads, a coverage study of the bed file used (if this is included as an input), a study of the optimal normalizations for each chromosome, and for the autosomes, an assessment of synthetic samples with partial or complete aneuploidies.
- A dataframe containing 48 columns that contain the average coverage values for each chromosome, the autosomal set, and the autosomal set excluding one autosome at a time for 20 synthetic samples (simulating complete or mosaic aneuploidies) for each autosome.
- A CSV file containing the top three normalizations for each chromosome.
- A CSV file containing the synthetic aneuploidies that were identified as significantly different for each autosome.
- A CSV file containing the beta-dispersion values obtained for the XX and XY cohorts with the various sex chromosome normalizations that were evaluated.
- A CSV file containing the standard deviation values for the various autosomes with the normalizations that were evaluated.

### 3. pool_study function:

This function detects aneuploidies in the pool samples by comparing a pool to a control cohort that has been previously evaluated. The aneuploidies report is generated in HTML format using two `.RData` files generated with the coverage_rdata function and a few files generated with the cohort_study function.

##### **Command:**

```bash
AneuploidiesStudy pool_study -p <pool.RData> -c <control.RData> -s <synthetic.RData> -n <bestnorms.csv> -x <signifsynth.csv> -o <output_dir> -f <output_report.html>
```

**`-p` / `--pool`**: `.RData` file with pool samples to analyze.

**`-c` / `--control`**: `.RData` file of the control cohort.

**`-s` / `--synthetic`**: `.RData` file with synthetic samples generated in the control cohort study.

**`-n` / `--bestnorms`**: CSV file with the best normalizations for each chromosome generated in the control cohort study.

**`-x` / `--signifsynth`**: CSV file with significant synthetic samples generated in the control cohort study.

**`-y` / `--thresholdsignif`**: (Optional) Threshold to define significantly different samples. Default value is 5.5.

**`-o` / `--outputdir`**: (Optional) Output directory. If not provided, the directory of the control `.RData` file will be used.

**`-f` / `--outputfile`**: (Optional) Name of the report in HTML format. Default value is `Pool_Aneuploidies_report.html`.

##### **Example:**

```bash
docker run aneuploidiesstudy:latest AneuploidiesStudy pool_study \
  -p /appdata/test_data/PoolCoverage_files/Coverage.RData \
  -c /appdata/test_data/ControlCoverage_files/Coverage.RData \
  -s /appdata/test_data/ControlCoverage_files/Synthetic_data.RData \
  -n /appdata/test_data/ControlCoverage_files/Best_normalizations.csv \
  -x /appdata/test_data/ControlCoverage_files/Significant_synthetic_samples.csv \
  -y 20
```

##### **Output:**

- An HTML report that displays the samples that were identified as outliers on the autosomes, as well as interactive graphs that allow users to compare the pooled samples to the control and synthetic significant samples on the autosomes and sex chromosomes.

### 4. merge_RDatas function:

This function merges RData files generated with the coverage_rdata function into one single RData. 

##### **Command:**

```bash
AneuploidiesStudy merge_RDatas -r <RDatas_dir> -p <RData_SelectionPattern> -o <output_dir> -f <output_file.RData>
```

**`-r` / `--rdats`**: Full path to the directory where `.RData` file that you want to merge are stored. (Generated using the coverage_rdata function)

**`-p` / `--pattern`**: (Optional) R pattern that could be used to identify the RData files that you want to merge in the directory (by default `"*.RData$"`).

**`-o` / `--outputdir`**: (Optional) Output directory. Default is the directory of the original RData files.

**`-f` / `--outputfile`**: (Optional) Output RData file name. Default is 'Merged.RData'.

##### **Example:**

```bash
docker run AneuploidiesStudy:latest AneuploidiesStudy merge_RDatas \
  -r /appdata/test_data/PoolCoverage_by_sample 
```

##### **Output:**

- Merged RData with all samples from the original RDatas.

## System Requirements

To run this tool, you need to have the following programs installed:

- **Docker**: Install Docker

The working environment is encapsulated inside a Docker container, which ensures the reproducibility of the analysis across different environments and facilitates its execution without relying on complex local configurations.

## Additional Notes

**Input Files**: Ensure that the coverage files generated by samtools depth are properly formatted and located in the specified path.

**Common Errors**:  If you encounter errors related to missing files or permissions, check that the file paths are correct and that the container has access to them.
